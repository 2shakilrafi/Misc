# MATLAB Numerical Experiments

Two small MATLAB functions retained as numerical-programming experiments.

## Files

- [`ilpackitpackmult.m`](ilpackitpackmult.m) — an experimental routine intended to expand an indexed sparse-row representation and multiply it by an input vector.
- [`torusknot.m`](torusknot.m) — generates a wrapped parametric line plot from integer-like parameters `p1` and `q1`.

## Run

Start MATLAB in this directory, then call a function with suitable inputs. For example:

```matlab
torusknot(2, 3)
```

These are compact, unvalidated educational snippets rather than a packaged library. Review and test the implementation before incorporating it into other work.
